# Portfolio de Thomas, graphiste freelance

Intégration HTML/CSS responsive de la maquette Figma « LearningCampus-maquette-portfolio ».

## Installation
1. Cloner le dépôt : `git clone <url-du-depot>`
2. Ouvrir le dossier dans VS Code.
3. Lancer `index.html` avec l'extension Live Server, ou ouvrir le fichier dans un navigateur.

Aucune dépendance : HTML5 et CSS3 uniquement.

## Police utilisée
Heebo (Google Fonts), avec Poppins en solution de repli.

## Structure
- `index.html` : page unique avec ancres (#accueil, #articles, #portfolio, #contact)
- `styles/style.css` : styles, variables de couleurs, points de rupture tablette (900 px) et mobile (700 px)
- `assets/img/` : images optimisées
- `assets/cv/` : CV au format PDF
